# VNC & Screens Remote Lab Setup

> **Track:** OpenClaw Real-World Lab Build (Track 3)
> **Course 2 of 5**

Configure Screens and VNC for multi-user, low-latency remote access to all 6 Mac Mini nodes.

---

## Modules

### Module 1: Screens 5 Configuration & Profiles

**Learning Objectives:**
- Create connection profiles for all 6 nodes
- Configure display resolution and color depth
- Set up saved credential vaults securely

### Module 2: VNC Security & Authentication

**Learning Objectives:**
- Enable VNC with strong passwords
- Restrict VNC access by IP whitelist
- Tunnel VNC over SSH for external access

### Module 3: Multi-User Session Management

**Learning Objectives:**
- Manage concurrent VNC sessions per node
- Configure macOS Fast User Switching for labs
- Audit active sessions and disconnect idle users

### Module 4: Bandwidth Optimization for Remote Access

**Learning Objectives:**
- Tune VNC compression settings
- Measure latency from target regions
- Configure adaptive quality for variable bandwidth
